📌 Descripción del Proyecto

SmartMaq es una plataforma SaaS (Software as a Service) diseñada para el sector maquilador en Tijuana, B.C. Integra automatización de procesos mediante inteligencia artificial, permitiendo optimizar operaciones empresariales.

🎯 Objetivo

Desarrollar un portafolio digital que documente la protección de propiedad intelectual de una innovación tecnológica, considerando el entorno empresarial de Tijuana.

🌳 Clasificación de Propiedad Intelectual

  • Software (Código fuente): Derecho de Autor (Protegido como obra literaria)
  • Marca (Nombre + Logo): Marca (Identificación comercial)
  • Algoritmos IA: Secreto Industrial (Ventaja competitiva)

🧠 Conclusión: Se utiliza una estrategia híbrida que combina Derecho de autor, Marca y Secreto industrial.

📊 Problema y 💡 Solución

Los ERPs tradicionales son rígidos, requieren configuración manual y no se adaptan rápido a normativas. La solución es una Plataforma SaaS con automatización low-code, IA para procesamiento de datos e integración con sistemas externos.

⚙️ Funcionamiento y Arquitectura

  • Entrada: documentos, datos -> IA procesa información -> Sistema ejecuta acciones automáticas.
  • Arquitectura: Frontend web, Backend en microservicios, IA integrada, Base de datos distribuida.
